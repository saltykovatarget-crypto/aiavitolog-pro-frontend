# Case images for BeforeAfter section

This folder contains static images used on the landing page in the "Cases" carousel.

## Required files

Place the following files into this directory:

- case-1-before.png
- case-1-after.png
- case-2-before.png
- case-2-after.png
- case-3-before.png
- case-3-after.png

## Notes

- Keep consistent aspect ratio (recommended: 16:9).
- Try to keep each file under ~1MB (optimize PNG or use WebP if you update paths in code).
- These files are served from `/cases/...` because they live under `public/`.
