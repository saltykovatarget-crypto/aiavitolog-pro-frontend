# DESIGN BRIEF — AI Авитолог PRO

Приводим в порядок дизайн сайта. Связка: Лера рисует в Claude Design, Claude Code верстает.

## Правила (обязательно)
- Сначала прочитай `CLAUDE_DESIGNER_GUARDRAILS.md` и убедись, что активна ветка `design/designer-ui-work`. В `main` и `backend` не лезь.
- Дизайн-система = реальные токены фронта (не выдумывать):
  - Шрифт **Inter**.
  - Лендинг — светлый (#ffffff). Приложение/кошелёк/чат — **тёмная тема** (`.dark`, фон-градиент #0A0D14 → #0C1020).
  - Акцент — фиолетовый **#6F42C1** (ховер #8257D6), кнопки-pill, мягкие тени.
  - Токены — в `src/styles/globals.css`.
  - **Эмодзи в интерфейсе не использовать.**
- Перед правкой пиши: ветка, какие файлы, зачем, есть ли риск задеть backend/платежи.
- После правки: отчёт + как проверить (`npm run dev`). Коммиты: `design: краткое описание`, пуш только в дизайн-ветку.

## Порядок экранов (приоритет)
1. **Кошелёк/оплата** — `WalletTopupPage` + страница `/wallet/requests`. Эталон вида — `topup.html` (тёмная тема, пакеты, баланс). Привести к нему.
2. **Чат** (основной экран после разблокировки Free): `NewChatArea`, `ChatHeader`, `Sidebar`, `ChatList` — единый чистый вид.
3. **Пейволл-диалог (402)**: «Купить запросы / Пополнить баланс» — аккуратно и продающе.
4. **#pricing** — причесать/переделать под кошелёк+пакеты (старые подписки убрать/спрятать).
5. **Юр-страницы** `/offer`, `/policies`, `/cookies` — оформление (финальный текст позже).
6. **Адаптив** (мобилка) + консистентность тёмной темы.

## Старт
Возьми экраны кошелька (`/wallet/topup` и `/wallet/requests`), запусти `npm run dev`, покажи текущий вид — причешем первым.
