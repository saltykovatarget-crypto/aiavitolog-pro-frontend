# Composer Component - Демонстрация

Реализован полнофункциональный компонент **Composer** со всеми требуемыми состояниями для панели ввода чата.

## 🎯 Реализованные состояния

### 1. **Пустое состояние** (`idle`)
- Неактивная кнопка отправки
- Доступна кнопка прикрепления
- Placeholder текст

### 2. **С текстом** (`typing`)
- Активная кнопка отправки
- Доступна кнопка прикрепления
- Автоматическое изменение размера textarea

### 3. **В процессе стрима** (`streaming`)
- Кнопка "Стоп" вместо "Отправить"
- Прикрепление недоступно
- Анимированные заглушки от ассистента

### 4. **Ошибка отправки** (`error`)
- Сообщение об ошибке под полем
- Кнопка "Повторить"
- Сохранение введенного текста

### 5. **Лимит вложений** (`attachLimit`)
- Отключенная кнопка прикрепления
- Tooltip "Лимит вложений исчерпан"

### 6. **Предпросмотр файлов**
- Карточки файлов с иконками по типу
- Кнопка удаления для каждого файла
- Подсветка ошибочных файлов красным
- Поддержка .docx, .xlsx, .csv

## 🔧 Технические особенности

### Компонент Composer
```typescript
interface ComposerProps {
  message: string;
  onChange: (value: string) => void;
  onSend: () => void;
  onStop?: () => void;
  onRetry?: () => void;
  state?: ComposerState;
  attachedFiles?: AttachedFile[];
  onFileAttach?: (files: FileList) => void;
  onFileRemove?: (fileId: string) => void;
  // ... другие props
}
```

### Типы состояний
```typescript
type ComposerState = 'idle' | 'typing' | 'streaming' | 'error' | 'attachLimit';
```

### Файловые вложения
```typescript
interface AttachedFile {
  id: string;
  name: string;
  type: 'docx' | 'xlsx' | 'csv';
  size: number;
  isError?: boolean;
  errorMessage?: string;
}
```

## 🚀 Демонстрация

Откройте приложение - по умолчанию загружается **ComposerDemo** с полным интерактивным тестированием:

### Панель управления
- Переключение между всеми состояниями
- Позиционирование (centered/bottom)
- Добавление тестовых файлов
- Тестовые сообщения
- Переключение темы

### Примеры использования
1. **Базовый флоу**: Пусто → набор текста → отправка → стрим → ответ
2. **С файлами**: Прикрепление → предпросмотр → отправка
3. **Ошибки**: Имитация ошибок отправки → повтор
4. **Лимиты**: Достижение лимита файлов → отключение attach

## 🎛️ Интеграция

Компонент **Composer** уже интегрирован в **NewChatArea** вместо старого **InputArea**. Все состояния работают с реальной логикой чата:

- Автоматический переход в состояние `streaming` при отправке
- Имитация ошибок (20% вероятность)
- Очистка файлов после успешной отправки
- Сохранение текста при ошибках
