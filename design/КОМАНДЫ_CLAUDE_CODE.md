## 🌗 ДОБАВЛЕНИЕ ПОДДЕРЖКИ СВЕТЛОЙ ТЕМЫ

```
Прочитай DESIGN_SYSTEM.md, особенно секцию про две темы.

Добавь поддержку светлой темы для компонента [НАЗВАНИЕ].

Важно: светлая тема нужна ТОЛЬКО для функциональных страниц:
- Чат с AI Авитологом
- /wallet
- /profile  
- Админка

НЕ нужна для лендинга, /partners, маркетинговых страниц.

Что сделать:
1. Найти все классы цветов в компоненте
2. Добавить парные dark:* и (без префикса) классы по таблице 
   из DESIGN_SYSTEM.md правило №1
3. Проверить контраст текста на обоих фонах
4. Проверить рамки карточек видимы в обоих темах
5. Иконки наследуют цвет от родителя через currentColor

Пример:
ДО:  className="bg-gray-950 text-white"
ПОСЛЕ: className="bg-white dark:bg-gray-950 
                  text-gray-900 dark:text-white"

После работы прогони тест:
- Переключи тему в браузере
- Все элементы остаются читабельными?
- Цвета не "вырвиглазные" в светлой теме?
- Карточки имеют видимые рамки?
```

## 📱 RESPONSIVE-АУДИТ

```
Прочитай DESIGN_SYSTEM.md, секцию правило №10 (Responsive).

Проверь страницу [URL или путь к файлу] на мобильном.

Проверь работу на:
- 320px (iPhone SE)
- 375px (iPhone 13 mini)
- 414px (iPhone 14 Pro Max)
- 768px (iPad mini)
- 1024px (iPad)
- 1440px (десктоп)

Что искать:
1. Текст не обрезается ("AI Авитолог" → "AI A...")
2. Кнопки помещаются и кликабельны
3. Карточки не вылазят за края
4. Нет горизонтальной прокрутки
5. Padding по краям достаточный (минимум 16px на мобильном)
6. Шапка не перегружена элементами
7. Иконки в шапке кликабельны (минимум 40x40px область клика)

Покажи список проблем — где ломается, какой класс надо добавить 
для исправления.
```
