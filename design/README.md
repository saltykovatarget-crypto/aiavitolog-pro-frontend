## 📁 СОСТАВ ПАКЕТА

### 1. `DESIGN_SYSTEM.md` — ЗАКОН ДИЗАЙНА
Главный файл. **Все правила в одном месте:**
- Цвета (тёмная + светлая темы)
- Размеры текста (шкала)
- Отступы (всё кратно 4px)
- Карточки и плашки
- Кнопки
- Поля ввода
- Иконки (lucide-react, не эмодзи)
- Анимации
- Структура страницы
- Responsive
- Запреты (что НЕЛЬЗЯ)

**Эту систему читает Claude Code перед каждой задачей.**

### 2. `АУДИТ_ДИЗАЙНА_ВЕРСИЯ_1.md` — СПИСОК ОШИБОК
Конкретный список **что сейчас плохо** на сайте и **как исправить**:
- 🔴 Критические ошибки (4 шт)
- 🟡 Средние ошибки (9 шт)
- 🟢 Мелкие улучшения (6 шт)

Чек-лист с приоритетом. По нему Claude Code исправляет сайт.

### 3. `КОМАНДЫ_CLAUDE_CODE.md` — ШАБЛОНЫ ЗАПРОСОВ
Готовые тексты команд для Claude Code:
- Создание компонента
- Правка существующего
- Аудит страницы
- Добавление светлой темы
- Responsive-аудит
- Исправление бага
- Создание новой страницы

**Принцип:** копируй шаблон → подставляй задачу → отправляй. 
Не пиши команды с нуля.

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### Первый запуск Claude Code в проекте

```
1. Положи все три файла в корень проекта (рядом с CLAUDE.md)
2. Открой Claude Code на Mac:
   cd ~/your-project
   claude
3. Первое сообщение:
   "Прочитай DESIGN_SYSTEM.md и АУДИТ_ДИЗАЙНА_ВЕРСИЯ_1.md.
   Расскажи что мы будем исправлять в первую очередь."
```

### Регулярная работа

```
Перед задачей → копируй шаблон из КОМАНДЫ_CLAUDE_CODE.md
После задачи → запускай чек-лист из DESIGN_SYSTEM.md
Раз в неделю → запускай АУДИТ СТРАНИЦЫ для контроля
```

### Если что-то идёт не так

Возвращайся к Claude (мне) с конкретным вопросом:
- «Claude Code сделал X, но это нарушает Y из DESIGN_SYSTEM. Что делать?»
- «Появилась новая проблема Z. Куда её записать?»
- «Можем ли мы упростить правило N?»

Я обновлю файлы и пришлю новую версию.

## 🛡 ЗАЩИТА ОТ ИВАНА

Чтобы Иван не правил CSS без апрува — попроси его настроить:

### 1. `.github/CODEOWNERS`

```
# Кто что может менять без апрува

/backend/                @ivan
/src/                    @lera  
/src/components/         @lera
/src/styles/             @lera
*.css                    @lera
tailwind.config.js       @lera
DESIGN_SYSTEM.md         @lera
```

### 2. Branch protection в GitHub

Settings → Branches → main → Protect:
- ✅ Require pull request before merging
- ✅ Require approvals (1 минимум)
- ✅ Require review from CODEOWNERS
- ✅ Dismiss stale approvals on new commits

**Результат:** Иван физически не сможет закоммитить CSS без 
твоего апрува. Каждое его изменение приходит к тебе на проверку 
через Pull Request.

Время настройки Иваном: ~30 минут.
